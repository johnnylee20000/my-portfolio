# My Portfolio

A modern, responsive personal portfolio website built with Next.js, TypeScript, and Tailwind CSS.

## Features

- 🎨 Modern and beautiful UI with gradient designs
- 📱 Fully responsive design
- ⚡ Smooth animations with Framer Motion
- 🚀 Built with Next.js 14 and TypeScript
- 🎯 SEO optimized
- 🌙 Dark theme

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Customization

1. **Personal Information**: Update your name, title, and bio in `src/components/Hero.tsx`
2. **About Section**: Modify the about content in `src/components/About.tsx`
3. **Skills**: Update your skills and proficiency levels in `src/components/Skills.tsx`
4. **Projects**: Add your projects in `src/components/Projects.tsx`
5. **Contact**: Update contact information in `src/components/Contact.tsx`
6. **Social Links**: Update GitHub, LinkedIn, and email links in `src/components/Hero.tsx`

## Build for Production

```bash
npm run build
npm start
```

- [Next.js](https://nextjs.org/) - React framework
